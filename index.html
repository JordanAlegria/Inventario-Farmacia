Sin conectar. Pega la URL de tu Apps Script (termina en /exec) para sincronizar con la Sheet compartida.

1. Escanear código de barra

La cámara nativa de este navegador debe soportar lectura de códigos (Chrome/Android funciona mejor). Presiona iniciar.
Alinea SOLO el código que quieras leer dentro del recuadro
Si tu navegador no soporta detección automática de códigos, puedes ingresar el código manualmente abajo (solo para probar el prototipo).

2. Resultado de la lectura

Este código no trae lote/vencimiento. Toma una foto del sector de la caja donde estén impresos.

Producto o laboratorio nuevo: se guardará en el catálogo para que la próxima vez se autocomplete solo.
Ej: si la caja dice "x1000 comp", pon 1000 aquí. Si no aplica (viene por unidad suelta), deja 1. Se guarda junto al producto, no hace falta repetirlo cada vez.
Escaneaste 1 código — si llegaron más cajas idénticas (mismo producto, mismo lote), indica cuántas en total. No necesitas volver a escanear cada una.
Total a registrar: 1 unidad/comprimido

Notas del prototipo

• Este demo guarda los datos en este dispositivo (almacenamiento local de la app), solo para probar el flujo.

• En producción, este mismo formulario escribiría directo a tu Google Sheets mediante un Google Apps Script Web App (una URL que recibe estos datos y los agrega como fila).

• El parser de GS1-128 reconoce (01) GTIN, (17) vencimiento y (10) lote — el mismo formato visto en tus fotos de MILAB y Grunenthal.

• La alerta FEFO se calcula comparando el vencimiento del lote nuevo contra el vencimiento más lejano ya registrado para el mismo producto genérico.
